# Karim Fakhry — Product Design Portfolio

Source for [karimfakhry.github.io](https://karimfakhry.github.io/), featuring product design case studies across healthcare, education, performance management, and design systems.

## Technology

- Next.js
- React
- TypeScript
- CSS
- GitHub Pages

## Local development

Requires Node.js 22 or later.

```bash
npm ci
npm run dev
```

Create the GitHub Pages static export with:

```bash
npm run build:github
```
